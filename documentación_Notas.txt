**** Descripción del sistema: ******

Easy Inventory es un sistema para la realización y análisis de inventarios físicos, consta de una aplicación para dispositivos Android en la que podrán capturar los conteos (incluso sin necesitar internet) y una aplicación web donde podrás monitorear el progreso en tiempo real.

El sistema web cuenta con las siguientes funciones:

* Importación de archivos. Mediante archivos de Excel preparas el sistema con la información de ubicaciones, items y cantidades de inventario.
* Gestión de Marbetes (Tags). Permite crear los marbetes a utilizar, imprimirlos y capturarlos por rango.
* Módulo de auditoría. Permite la asignación de tags para ser recontados y validar su veracidad.
* Módulo de captura. Además de registrar conteos mediante la aplicación Android, también es posible hacerlo desde el sistema web.

** Reportes **
* Reporte total de captura. Visualizar y descargar toda la captura realizada en el inventario.
* Reporte de progreso. Visualiza en tiempo real el avance del conteo por cada área.
* Despliegue de marbetes auditables y su resultado.
* Reporte de variación de cada Item (Producto). En cantidad y dinero.
* Cantidad de marbetes contados por área/producto.
* Cantidad de marbetes contados por área/usuario.
* Todos los reportes son exportables a Excel.

* Módulo para gestión de base de datos. Posibilidad de hacer respaldos, puntos de control, limpieza, nuevo inventario.
* Sistema con textos en inglés y español.
* Impresión de etiquetas de productos.
* Gestión de usuarios. Crea los usuarios que tendrán acceso al sistema y los conteos con diferentes niveles de permisos.
* Módulo de escaners. Complemento para el registro de asignación de dispositivos a las personas que contarán.

La aplicación Android cuenta con las siguientes funciones:

* Posibilidad de funcionar con internet intermitente o sin el.
* Acceso mediante usuario/contraseña.
* Módulo de captura. Escaneo de marbete, producto, ubicación, cantidad.
* Posibilidad de Editar o corregir conteo previo de marbete mediante clave especial de supervisor.
* Módulo para auditoría de marbetes.
* Se puede usar escaner con Android o celulares (Función de escaneo con cámara integrada)
