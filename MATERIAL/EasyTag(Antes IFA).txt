Descripción:
Easy inventory es un sistema web y una aplicación Android para la realización de inventarios físicos.

Características principales:
- Sistema web y aplicación Android para rápido conteo.
	La aplicación Android puede usarse sin internet, con hand held o un teléfono celular.
- Fácil de usar, en 5 sencillos pasos puedes comenzar a registrar conteos.
- Reportes en tiempo real del avance y variación de los conteos.
- Exporta todos los datos resultantes a Excel.
